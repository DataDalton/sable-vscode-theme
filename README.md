# Sable

A dark VS Code theme built on deep blacks with subtle steel-blue accents.

## Install

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Sable"
4. Click Install
5. Go to Preferences > Color Theme and select **Sable**

## Colors

- **Backgrounds:** Near-black tones (`#0f1012`, `#0a0a0a`, `#0e0e0e`)
- **Accent:** Steel blue (`#4d9bc8`, `#1a6f8a`)
- **Foreground:** Soft grays (`#cacaca`)

## Manual Install

```bash
npm install -g @vscode/vsce
cd sable-vscode-theme
vsce package
code --install-extension sable-theme-0.1.0.vsix
```
